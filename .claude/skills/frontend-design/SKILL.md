# Frontend Design

Build interfaces with a bold, intentional aesthetic direction executed with precision. Refined minimalism and confident maximalism both work — the key is intentionality, not intensity.

## Decide first
- Purpose, audience, tone. Pick a clear conceptual direction (playful / editorial / brutalist / luxury / organic …) and commit.
- Ask: what makes this screen memorable rather than forgettable?

## Typography
- Use distinctive, characterful fonts. Avoid generic defaults (Inter, Roboto, Arial, system-ui).
- Pair a distinctive display face with a refined body face. Use weight, size, and tracking deliberately.

## Colour & theme
- Commit to a cohesive palette via CSS variables. Prefer dominant colours with sharp accents over timid, evenly-weighted palettes.
- Avoid clichés (generic purple gradients).

## Spatial composition
- Break rigid grids: use asymmetry, overlap, diagonal flow, and intentional whitespace.
- Don't let content bunch or float in dead space — distribute with rhythm. Connect related elements visually.

## Visual detail & depth
- Add atmosphere: soft gradient washes, layered shadows, texture/noise, depth. Avoid flat, characterless surfaces.

## Motion
- Prefer CSS/lightweight solutions. Focus on high-impact moments: staggered load reveals, scroll triggers, hover surprises.

## Avoid (AI slop)
- Generic fonts, predictable centered single-column layouts, evenly-floating elements with no connection, flat surfaces, cookie-cutter spacing.

## Implementation
- Scale effort to the vision: minimalism demands precision in spacing/typography; maximalism demands elaborate, cohesive detail.
